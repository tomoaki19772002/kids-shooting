# SYU & RYO サボテン大作戦

スマホで遊べるシューティングゲーム。`index.html` を開くだけで遊べます。

- タイトルで SYU か RYO を選んで 1 人で戦う(SYU=ひろがるトゲ / RYO=まっすぐ連射)
- 指でドラッグして移動、弾は自動発射
- ボスを倒すとステージが進み、背景と敵が変わる(さばく→ジャングル→うみ→ゆきやま→うちゅう)
- アイテム: ⭐パワー / ⚡連射 / 🛡バリア / 💣ボム / 🎯ホーミング(10秒) / ❤ライフ`n- 難易度を3段階(かんたん・ふつう・むずかしい)から選べる(ハイスコアも別々)`n- BGM は WebAudio で生成(右上のボタンでオン/オフ)
